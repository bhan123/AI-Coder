# 板块情绪与拥挤度：界面设计系统

视觉规范以 [桌面概念](dashboard-desktop-concept.png) 和 [移动端概念](dashboard-mobile-concept.png) 为准。

- 背景：`#08111e`；侧栏：`#0b1624`；表面：`#101c2a`；边框：`#243447`。
- 主文字：`#f3f7fc`；次文字：`#8fa1b5`；强调色：`#56a3ff`。
- 风险色：红 `#ff6258`、橙 `#ff963f`；情绪色：青 `#44c0c6`；覆盖色：紫 `#9b8cff`。
- 间距以 4/8px 为基准；表面圆角 10px；控件最小触控尺寸 44px。
- 桌面保持 280px 左侧板块栏；主工作区使用开放式面板、表格和图表。
- 800px 以下侧栏变抽屉，指标 2×2，板块对比由八列表格变为纵向列表。
- 所有帖子标题和板块名必须以 `textContent` 渲染，禁止拼接进入 `innerHTML`。
