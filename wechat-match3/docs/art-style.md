# 美术风格定调 — 微信层叠三消

> 目标用户：上班族通勤碎片时段（地铁/公交/排队），单局 2~5 分钟，轻量治愈、零负担。

## 1. 整体风格定位

**推荐方向 D：糖果色萌系。** 理由：目标场景是通勤治愈，单局 2~5 分钟需要最快速的情绪提振——糖果色高饱和度在手机小屏上一眼"亮"、认知成本最低；粉色 + 鹅黄 + 天蓝的撞色能产生"拆盲盒"的视觉快感；圆角大字号在 60fps 下抖动感最轻，不刺眼。一句话定调：**"高饱和糖果撞色 + 圆润厚边图标 + 弹性缓动"**。治愈系太静、像素风太硬、扁平微质感太"成熟"，都不如糖果色萌系适合碎片解压场景。

## 4. 牌面图案设计

**主题：拟物水果** —— 6 种主图案辨识度高、配色天然撞色，无需画师系列化设计。

### 6 种主图案

| ID | 名称 | 主色 | 辅色 | 轮廓 |
|----|------|------|------|------|
| 0 | 草莓 | `#FF5A5A` | `#FFD166` 籽点 | 3px 白色厚边 |
| 1 | 柠檬 | `#FFD166` | `#7AE0B5` 叶片 | 3px 白色厚边 |
| 2 | 蓝莓 | `#7AC8FF` | `#4A2E3A` 高光 | 3px 白色厚边 |
| 3 | 葡萄 | `#9B7AE0` | `#FFD166` 高光 | 3px 白色厚边 |
| 4 | 西瓜 | `#FF6B8B` | `#7AE0B5` 皮边 | 3px 白色厚边 |
| 5 | 猕猴桃 | `#7AE0B5` | `#4A2E3A` 籽 | 3px 白色厚边 |

### Bomb 牌视觉

- 底色：番茄红 `#FF5A5A` 圆形 + 深咖 `#4A2E3A` 描边
- 中心图标：黄色闪电符号 `#FFD166`，加 1px 白色外发光
- 附加：右下角旋转的小火焰贴纸（`#FF5A5A` → `#FFD166` 渐变），帧动画 8 帧循环
- 辨识要点：**深色描边 + 闪电符号**，3m 距离仍可辨认

### Wild 牌视觉

- 底色：从粉 `#FF6B8B` 顺时针渐变至黄 `#FFD166`、蓝 `#7AC8FF`、绿 `#7AE0B5`（四色渐变放射）
- 中心图标：四芒星 `#FFFFFF`，加 `0 0 8px #FFFFFF` 发光
- 附加：脉冲边（scale 1.0 ↔ 1.05，1.2s 循环），强烈节奏感
- 辨识要点：**彩虹底色 + 白星 + 脉冲**，不会与水果混淆

### 牌背设计

- 主色：鹅黄 `#FFD166` + 白色斜条纹（45°）
- 中心：圆角白圆 + 蜜桃粉 `#FF6B8B` 蜜桃轮廓小图标
- 用途：仅在 `backFrame` SpriteFrame 生效时显示，主要在洗牌/翻牌时短暂可见

### 牌尺寸

- 默认 80x80px（基于 `cellWidth/cellHeight = 80`，level JSON 已有）
- 层间 z 偏移 30px（`layerOffset = 30`），保证 3D 堆叠视觉层次

## 5. UI 元素清单

### 按钮风格

- 圆角半径：`12px`（大按钮）/ `8px`（小按钮/icon）
- 阴影：`0 4px 0 rgba(74,46,58,0.25)`（向下偏移 4px 的硬阴影，按下时缩为 2px）
- 按下反馈：scale `1.0 → 0.95`，0.1s（参见动效章节）
- 描边：2px 白色内描边（仅主色按钮）

### 字号层级

| 层级 | 大小 | 用途 |
|------|------|------|
| 标题 | 36pt | 弹窗主标题、菜单游戏名 |
| 副标题 | 24pt | 关卡号、分数大字 |
| 正文 | 18pt | 按钮文字、HUD 标签 |
| 小字 | 14pt | 版本号、辅助说明 |

### 字体推荐

**思源黑体（Source Han Sans / Noto Sans CJK）** —— 免费商用、中文渲染清晰、小字号不掉辨识度。备选：站酷高端黑（标题更厚实）。**不推荐**仓耳渔阳体（笔触装饰过强，在小尺寸 HUD 上糊）。

### 弹窗规范

- 遮罩：`rgba(0,0,0,0.6)`（对话弹窗统一）
- 弹窗卡片：白底 `#FFFFFF`，圆角 `20px`，宽度 600px，垂直居中
- 入场动画：scale `0.8 → 1.0` + opacity `0 → 1`，0.25s ease-out

## 6. 动效方向

| 场景 | 参数 |
|------|------|
| 牌消除 | scale `1 → 0` + opacity `255 → 0`，0.25s ease-in（已实现 `playRemoveAnim`） |
| 通关特效 | 彩纸屑粒子，2s 持续，从屏幕顶部散落 |
| 失败反馈 | 屏幕 shake（位移 ±8px，0.4s）+ 红光叠加层闪一下（0.3s 淡出） |
| 按钮按下 | scale `1 → 0.95`，0.1s |
| 槽位入牌 | 弹性 ease-out 0.2s（cubic-bezier(0.34, 1.56, 0.64, 1)） |
| 通关弹窗 | scale `0.8 → 1.0` + opacity `0 → 1`，0.25s |
| Bomb 触发 | 屏震 0.3s + 黄色闪光 + 圆形扩散波纹 |

> 现有 `Tile.playRemoveAnim()` 的 `t = 0.25` 与 ease-in 方向已与定调一致，无需重写。

## 8. MVP vs 正式版取舍

### MVP（当前开发阶段）美术占位

- **牌面**：纯色块 + 字母/emoji 占位（6 种颜色对应 6 种图案 ID），不做美术
- **背景**：`#FFF4F0` 单色 + 一行斜纹 Sprite 装饰
- **按钮**：Cocos Button 默认灰色按钮 + 文字标签（不画圆角+阴影）
- **HUD**：Cocos 默认 Label 字体，无图标
- **弹窗**：白底矩形 + 黑色文字，无描边无圆角

### 正式版必须投入的美术项

| 项 | 优先级 | 说明 |
|----|--------|------|
| 6 张主牌面图案 | P0 | MVP 占位仅靠颜色区分，辨识度差，正式版必上 |
| Wild/Bomb 特殊牌 SpriteFrame | P0 | 玩法标识，必须有清晰视觉 |
| 牌背 backFrame | P0 | 翻牌动画使用 |
| 高亮 highlightFrame | P1 | 选中态视觉反馈 |
| 主菜单 + 关卡选 UI 套图 | P1 | 首屏定调 |
| 三个弹窗白底卡片 | P1 | 圆角+阴影 |
| 道具按钮 icon | P2 | undo/shuffle/remove 三个 |
| 通关彩纸屑粒子 | P2 | 加分项 |
| BGM + 5 个 SFX | P1 | click / win / lose / bomb / match |
| 失败红光 / 屏震 shader | P2 | 加分项 |

MVP 与正式版共用同一套 TypeScript 逻辑（无美术代码侵入），切换只需替换 SpriteFrame 资源 + Cocos 场景的 Sprite 引用，对开发节奏零阻塞。
