## V1 原则

- 在 14:30–15:00 的全市场快照上运行；
- 选取日内明显下跌、从低点回升、相对指数更强、且具备基础流动性的股票；
- 将每次输入、版本、因子和排名落库，未来才能无未来函数地回测；
- 策略、因子权重和数据源均可替换。

## T+1 / T+3 / T+5 回测口径

回测不是回答“第二天最高价有没有比买入价高”，而是回答：**若我在当时真的买入，并按预先写好的纪律退出，是否能够盈利离场。**

每个信号至少保留以下不可变记录：

- `signal_at`：尾盘快照时刻；V1 设为 14:30–15:00 的可配置时段。
- `entry`：信号后可成交的价格（生产环境应使用下一笔/下一分钟 VWAP，而不是同一根 K 线的收盘价）。
- `next_day_path`：次日开盘至设定截止时刻的分钟级可交易价格序列；扩展支持 T+3 / T+5 的日线作为长持有期评估。
- `exit_policy`：包含双边成本、隔夜跳空、止损、移动止盈和最晚退出时刻。
- `strategy_version` 与完整因子快照：确保未来新增逻辑后，老结果仍可复现。

页面同时给出三项不能混为一谈的指标：

1. **触及盈亏平衡率**：次日真实价格路径是否曾超过买入价加成本；它表示“有无机会”。
2. **规则化盈利退出率**：按预先固定的止损/回撤止盈/时间退出规则，是否实际盈利离场；它表示“策略能否执行”。
3. **夏普 / 最大回撤**：所有候选按等权配置得到的累计净值曲线的统计指标；它表示“策略的稳健性”。

产品页面和公开运行接口只使用实时行情；测试夹具中的样例不在产品中展示或运行。真实回测必须先积累带时间戳的尾盘快照，再补齐同一标的次日分钟级价格路径；不能用次日最高价倒推胜率。

### 盘中涨停伏击预警

- 新预警时段：交易日 `09:35–10:30`、`13:30–14:30`，每 2 分钟扫描一次。服务启动后先积累最近 3 个快照（约 4 分钟）再允许预警；当天出现预警后，会在 `09:35–11:30`、`13:00–15:00` 继续只跟踪已预警股票，并在 14:57 后归档当日结果；其余时段不请求行情。
- 预警强度按股票对应交易板归一化为“涨停进度”，只接受涨停进度 `40%–94%`：主板约对应涨幅 `4%–9.4%`，创业板/科创板约对应 `8%–18.8%`，北交所约对应 `12%–28.2%`，不再用同一涨幅阈值混筛不同交易板。
- 个股必须在最近 3 个两分钟快照中价格和涨幅连续抬高，累计增强至少 `0.3` 个百分点；量比至少 `1.5`、换手率至少 `3%`，从而过滤冲高后持续回落但仍处于高涨幅的股票。
- 大盘与板块退潮信号作为硬开关：指数涨幅不得低于 `-1%`，全市场上涨家数占比至少 `35%`；同业平均涨幅至少 `1%`，最近 3 个快照不得走弱，同时至少 3 只同业同步上涨且个股显著强于同业平均。
- 历史复盘按“交易日 + 股票”合并重复预警，保留首次/末次预警时间、连续增强次数、最高评分和预警后的 2 分钟轨迹；增强至少 3 次定义为“持续增强”。旧版记录仍显示“命中次数”，同一天混有新旧记录时明确显示“命中/增强次数”，避免改变历史含义。
- 结果跟踪记录预警后的最高涨幅、相对预警价的最大涨幅/最大回撤、是否触及对应交易板涨停阈值及首次触及时刻。主板按约 10%、创业板/科创板按约 20% 判断。
- 只写入触发预警的候选、扫描元数据和这些候选后续的轻量行情点，**不**每两分钟保存完整市场快照；预警历史独立展示，不进入 V1 的历史回看或 T+1 复盘。
- 公共行情不含稳定的逐笔成交和实时封单数据，故页面明确标为“观察预警”，不自动交易、不承诺涨停或封板。

`tail-stock-outcome.timer` 的 10:35 结果是**规则退出结果**：只使用次日上午 09:30–10:30 的分钟路径，按既定止损和回撤纪律模拟，不能代表股票当天最终涨跌。随后同一个工作日 14:50，`tail-stock-capture.timer` 会在不影响正式选股快照的前提下，把这些已完成 T+1 记录补上截至 14:50 的真实分钟走势（开、高、低、截至价和分时点）。

页面的“昨日推荐复盘”读取最新一个已完成的 T+1 复盘日：因此在工作日 14:50 查看新一轮 V1 推荐时，会同时看到上一交易日每只推荐股的信号参考价、规则退出价、净收益和退出原因，以及单独展示的次日分时/K 线。规则退出仍用于检验纪律，图表用于查看当日实际波动，两者不是同一个收益口径；旧记录会明确标记为“待积累”。

采集按策略独立容错：P1/P4 的板块源、P2/P3 的日线或分时源若失败，会在服务日志中标出该策略失败，但不会中断其余策略的正式采集。

### P1 v1.1 硬门槛

- 个股当日涨幅 1%–5%，板块涨幅至少 0.5%，且板块位于当日涨幅前 30%；
- 同板块至少 3 只其他股票同步上涨，且个股涨幅不低于板块平均，拒绝单股独舞和弱跟涨；
- 从开盘到信号时刻至少 60% 的分钟切片位于累计 VWAP 上方；
- 14:00–14:35 的回踩均量低于 13:30–14:00 均量的 70%，回踩不有效跌破 VWAP；
- 14:35–14:55 相对回踩低点至少回升 0.2%，信号时刻处于日内振幅上方四分之一；
- 最后 15 分钟单分钟跳涨不得超过 1%，继续排除尾盘直线抢筹。

### P2–P4 实盘数据口径

- P2 的 13:30–14:30 平台、14:30 后 VWAP 确认均使用“开盘后交易分钟”索引，规避午休造成的自然时钟错位；
- P3 的平台只取已完成交易日，今日突破高度、维持时间、实时量能和上影线全部来自当日分钟线；
- P4 的龙头身份优先采用数据源标识；缺少龙头代码时，以同板块快照中的个股涨幅排名判定，绝不使用板块强度排名替代。

## 策略参数可调

每个策略的阈值都封装在对应 `*Config` dataclass 里，通过 `current_config()` 暴露给前端。通过 `POST /api/strategies/{id}/config` 可以提交 dict 形式的覆盖：

- 非法字段忽略，避免外部脏数据把研究链路打挂。
- 覆盖立即生效，下次 `run_strategy` 时按新阈值判定。
- 前端"参数调优"按钮打开抽屉式面板，列出当前所有可调字段。

`POST /api/strategies/{id}/preview` 在任意时刻返回实时行情中的合格候选 + 接近合格的近失分股票，便于调参时直观看到阈值变化的影响。

`run_all_strategies` 在窗口外也允许跑，便于做空仓告警。

## 标签语义（不再假装已实现）

`PriorityTag.status` 的取值：

- `matched`：策略核心条件全部满足，是该信号的主策略。
- `partial`：相关数据齐全但某些阈值未过；展示真实证据。
- `missing_data`：关键数据缺失（板块、日线、分时等），策略无法判定。
- `excluded`：明确不属于该策略（如 V1 不收尾盘急拉）。

旧 V1 的"待验证"现在会根据上下文是否提供板块/历史/分时自动切换：板块数据存在就升级为 `partial` 并写明真实证据；分时和日线都缺时仍标 `missing_data`，但 evidence 不再说"待接入"。

## 历史回测样例

`scripts/backtest_history.py` 在最近 N 个交易日 14:30 模拟运行 P1–P4 + V1，用真实日线检查 T+1 / T+3 / T+5 的开盘 / 最高 / 最低 / 收盘。结果写到 `backtest_results.csv`，并打印：

```

  T+1 触及盈亏平衡率：80.8%
  T+1 收盘上涨率：59.6%
  T+1 收盘涨跌幅均值：1.91%  夏普：0.30  最大回撤：-35.19%
  T+1 最大涨幅均值：6.12%
  T+1 最大回撤均值：-3.08%
  T+3 收盘上涨率（18 个有数据）：38.9%  均值 -0.18%
  T+5：无足够历史计算

  p3-platform-breakout: n=52 T+1触及=80.8% 收盘上涨=59.6% 均值=1.91% 夏普=0.30 回撤=-35.19% T+3:7/17

  score >=70: n=24 收盘上涨=50.0% 均值=-0.08%
  score 65-70: n=12 收盘上涨=83.3% 均值=+5.45%
  score <65:   n=16 收盘上涨=56.2% 均值=+2.24%
```

### 初步结论（基于 2026-07-15 ~ 2026-07-31 的 P3 候选）

- 仅 P3 跑出了候选：V1 / P1 / P2 / P4 需要盘中分时或板块归属，目前公开接口没有可回溯历史，所以老实标记 `missing_data`，不参与数字。
  - V1 在弱市中相对强度门槛过严，2026-07-22 后市场弱势使 V1 候选不足 5 只，是预期行为。
  - P1 / P4 的板块归属走东方财富 `f127`，当前网络环境代理屏蔽该域名；生产可走 akshare 替代。
- 平台突破（P3）在最近 10 个交易日里给出 52 个候选，触及盈亏平衡 80.8%、收盘上涨 59.6%、均值 +1.91%；盈亏比约 2.3:1。
- 但 **T+3 比 T+1 显著恶化**（均值 -0.18%，上涨率 38.9%）：P3 突破在 T+1 兑现大部分涨幅，到 T+3 已被市场消化；不应当作"买入持有 3 天"的策略。
- 高分组（score ≥ 70）的均值回落到 -0.08%，中分组（65–70）反而 +5.45%。说明 P3 的"score 越高越准"假设需要重新审视，可能存在"突破后追高"的风险；建议把 65–70 区间作为当前最具操作价值的子集。
- 样本期只有 10 个交易日、且不含熊市检验；数字远不能作为胜率结论，仅说明链路可走通、数据不假。

### 后续要把全部策略纳入真实回测

- V1 / P2：需要把盘中分笔 → 历史回放，目前公开接口只能拿到 5 个交易日以内的分时，需要自建日线增量。
- P1 / P4：需要可回溯的板块历史（申万 / 中信 / 同花顺），akshare 的 `stock_board_industry_name_em` 仅返回当日最新值。
- 必须先把"signal_at"真实化为盘中 tick（例如腾讯分钟线的最近一根），再用 14:30 切片回放。
- 把候选 score 与真实胜率的相关性画出来，验证"P3 score 越高越准"的假设。
