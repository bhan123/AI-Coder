# 模板 04：操作持仓

适用场景：今日操作密集（加仓/减仓/调仓），或市场处于关键决策点，重点是"为什么这么做"。关键词：加仓、减仓、清仓、持仓、调仓、试错、按计划、心态。

代表帖：
- 0923复盘：克服恐惧，勇敢加仓 (3520 字)

---

## 风格规则

- **主旋律**：决策有理有据，强调"按计划"和"心态管理"
- **核心叙事**：今天做了什么 → 为什么（基本逻辑 + 技术信号 + 心态）→ 预期结果
- **风格关键词**："克服恐惧"、"按计划行事"、"勇敢加仓"、"持仓为主"
- **心态维度**：会主动写"克服了恐惧"、"受到诱惑但没动"、"持仓体验很差但逻辑没破"
- **关键术语**：试错仓位、底仓、加仓区间、止损位、左侧/右侧

## 标题模板

```
MMDD复盘：{克服恐惧，勇敢加仓 | 按计划行事 | 持仓为主 | 调仓完成 | 试错开始}
```

## 内容结构（1500-3500 字）

```
【今日操作】
1. {股票}：{具体动作（加仓 XX 元 @XX 元；减仓 XX 股；清仓）}
2. ...
{每只都写清楚价格、数量、占比}

【今日洞察】
1. 大盘
   {与今日操作相关的市场环境判断}

2. 板块
   {与今日操作相关的板块判断}

3. 个股
   {每只操作对应的个股分析 + 操作逻辑}

【写在最后】
{免责 + 鼓励 + 心态话}
```

## 调用 prompt

```markdown
你是虎扑用户「巴萨主教练弗里克」的写作风格模仿助手。请基于以下今日市场数据，按「操作持仓」模板写一篇 MMDD 复盘帖：

## 今日数据
{今日有重大操作（加仓/减仓/清仓），具体股票、价位、数量、当前持仓占比}

## 写作要求

1. **标题**：MMDD 复盘：{克服恐惧 + 加仓 | 按计划行事 | 持仓为主 | 调仓完成}
2. **结构**：6 段标准结构，重点是「今日操作」和「个股」的呼应
3. **风格**：
   - 主动写"心态变化"（克服恐惧/忍住不动/受到诱惑但没追）
   - 每笔操作都要写清楚**逻辑**（为什么这个价位？为什么这个量？）
   - 给出"如果错了怎么办"的应对
4. **避免**：
   - "我觉得可能会涨所以买了"等无逻辑表达
   - 没有应对方案的孤立操作
   - 不承认心态影响的纯理性叙事
```

## 反模式

- ❌ 写成"今天抄底了XX，希望反弹"
- ❌ 只说"加仓"不说价位/数量
- ❌ 没有操作逻辑只描述动作
- ❌ 隐藏心态影响（这人风格就是会主动暴露）
