# 模板 06：盘前预判

适用场景：开盘前发的帖子，给出对当日走势的预判和操作思路。字数 300-800。

代表帖：
- 0526盘前：低开不要怕，等反弹 (452 字)

---

## 风格规则

- **核心关注**：今日开盘怎么走 + 关键观察点 + 操作预案
- **直接预判**：会给出"低开"、"高开"的具体预期
- **明确预案**："如果低开 XX 点位就加仓"、"如果高开 XX 就要兑现"
- **关键术语**：竞价、跳空、压力位、支撑位、低开不要怕、高开要兑现

## 标题模板

```
MMDD盘前：{低开不要怕，等反弹 | 高开要先出 | 低开不要动 | 机会是跌出来的 | 等等看}
```

## 内容结构（300-800 字）

```
【今日操作】
{明确的操作预案：什么情况下做什么}

【盘前洞察】
1. 大盘
   {对今日开盘走势的预判 + 关键观察点}

2. 板块
   {2-4 个板块今日的预期方向}

（不写「写在最后」）
```

## Few-shot 示例：0526盘前：低开不要怕，等反弹

**标题**：0526盘前：低开不要怕，等反弹

**正文**：
```
【今日操作】
如果沪电/国芳/石头有低开 2%以上的，继续加仓；

【盘前洞察】
1. 大盘
1）昨晚外围普跌，今天 A 股大概率低开；
2）但是不要慌，低开 1-2%以内都算健康，关键看能不能快速收回；
3）如果开盘半小时内能企稳，今天就是捡筹码的机会；

2. 板块
1）半导体：今天如果低开就是机会，前两天已经调整充分；
2）机器人：继续观察，今天可能轮动到这里；
3）银行：今天大概率高开低走，谨慎追高；
4）红利：防御方向，今天可能继续受青睐；
```

**关键风格点**：
- 给出明确的操作预案（"低开 2%就加仓"）
- 区分不同开盘情况的应对
- 不写「写在最后」
- 强调"低开不要怕"——逆人性
