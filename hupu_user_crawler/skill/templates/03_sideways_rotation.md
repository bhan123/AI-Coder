# 模板 03：震荡轮动

适用场景：大盘没明确方向，板块之间快速切换，赚钱效应一般。关键词：轮动、分歧、缩量、抱团、高低切、风格切换、主线不清晰。

代表帖：
- 0226复盘：又开始轮动了 (1714 字)

---

## 风格规则

- **主旋律**：主线不明确是常态，关键看"资金在试什么方向"
- **核心叙事**：当前主线状态（抱团 vs 高低切）→ 各板块相对强弱 → 对轮动节奏的判断
- **板块视角**：分析哪些板块在"接棒"，哪些在"退潮"
- **个股视角**：持仓股是否还属于主线？是否需要切换？
- **关键术语**：抱团、高低切、轮动、主线、退潮、风格切换、量能持续性

## 标题模板

```
MMDD复盘：{轮动 | 分歧 | 缩量 | 高低切 | 抱团瓦解 | 主线不清晰}
```

变体：`MMDD复盘：又开始轮动了`、`MMDD复盘：缩量轮动`、`MMDD复盘：结构性上涨，结构性分歧`、`MMDD复盘：缩量普涨，喜气洋洋`

## 内容结构（1200-2000 字，比反弹/下跌短）

```
【今日操作】
{每只持仓的具体动作}

【今日洞察】
1. 大盘
   1）走势：{点位、小阳/小阴/十字星}
   2）量能：{缩量/平量，强调持续性}
   3）赚钱效应：{涨跌比、是否轮动特征}
   {主线判断}

2. 板块
   {按主线地位排序的板块点评}

3. 个股
   {持仓股分析}

【写在最后】
```

## 反模式

- ❌ 写成"今天市场震荡，后市方向不明，建议轻仓观望"——太空洞
- ❌ 列举所有板块做无重点的板块综述
- ❌ 给持仓股每一只都写长篇分析（震荡市持仓分析应简短）
- ❌ 标题写成"震荡市如何操作"等说教式
