# 模板 05：盘中快评

适用场景：盘中或盘后短评，针对当天的某个具体动作或快速观点。字数 200-500。

代表帖：
- 0102盘中：反包预期不高 (232 字)
- 0318复盘：缩量上涨，资金还在避险观望 (短)
- 0321午盘：先不要恐慌 (短)

---

## 风格规则

- **极简**：1-2 段，3-5 个观点，不展开
- **直接判断**：给出明确观点（"反包预期不高"、"先不要恐慌"），不绕弯子
- **核心关注**：早盘/盘中关键点位、异动板块、热点持续性、要不要操作
- **关键术语**：反包、低开高走、高开低走、避风港、兑现

## 标题模板

```
MMDD盘中：{反包预期不高 | 低开不要怕 | 高开要兑现 | 先不要恐慌 | 缩量上涨}
```

变体：`MMDD午盘：xxx`、`MMDD盘前：xxx`（盘前用模板 06）

## 内容结构（200-500 字）

```
【早盘/盘中/今日操作】
{1-2 句话的具体动作或不做动作}

【早盘/盘中洞察】
1. 大盘：{1-2 句话判断}
2. 板块：{1-2 个关键板块 + 1 句话点评}
3. 个股：{只点持仓股最关键变化}

（不写「写在最后」）
```

## Few-shot 示例：0102盘中：反包预期不高

**标题**：0102盘中：反包预期不高

**正文**：
```
【今日操作】
如果柯力跌到58-59区间，开始建仓；

【早盘洞察】
1. 大盘
1）不要指望大盘节后第一天冲上3400，从竞价看很多资金都还是休息状态，顶板情绪一般；整体还是延续周二的走势，低开；
2）大盘今天是弱修复预期，如果周二补仓了，3375附近考虑降仓位；

2. 板块
1）铜缆：还是出逃预期，每次反弹都是离场信号；
2）互联金融：目前看不到第三波行情的预期，耐心等；
3）机器人：只考虑做做趋势票的低吸，不要去追涨；
4）半导体：还没止跌信号，多看少动；
```

**关键风格点**：
- 没有「写在最后」
- 每条点评一句话，不展开
- 直接给出操作价位（"柯力跌到58-59"）
- 标题就是结论

## 今日数据
{用户输入：早盘/盘中走势、异动板块、关键点位}

   - 【今日操作】（1-2 句话，可写可不写具体动作）

   - **不写「写在最后」**

   - 字数严格控制在 200-500 字
   - 每条点评一句话，不展开
   - 标题就是结论
   - 给出明确判断，不模棱两可

## 反模式

- ❌ 写得像完整复盘（1500+ 字）
- ❌ 没有具体结论的"今天市场复杂，多看少动"
- ❌ 加「写在最后」免责声明（盘中帖不带这个）
- ❌ 写成"今日操作+今日洞察+大盘+板块+个股+写在最后"完整结构
