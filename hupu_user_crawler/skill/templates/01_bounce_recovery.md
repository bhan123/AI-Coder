# 模板 01：反弹修复

适用场景：大盘/个股从低点反弹，或处于底部修复阶段。关键词：反弹、修复、回踩、企稳、止跌、确认、右侧试错。

代表帖：
- 0805复盘：继续修复 (3133 字)
- 0804复盘：轮动修复 (1303 字)

---

## 风格规则

- **主旋律**：强调"反弹还在延续"但要"观察回踩质量"。"不要因为担心踏空直接重仓"
- **核心叙事**：从极端超跌反弹 → 站上均线 → 等待第一次回踩 → 区分"反弹"和"反转"
- **板块视角**：超跌反弹强的板块（PCB/光模块/电池/机器人/商业航天）通常是反弹主线
- **个股视角**：连续阳线后看 10 日线能否守住；回踩缩量是关键信号
- **关键术语**：高低切、轮动修复、缩量回踩、B 浪反弹、右侧试错、结构修复

## 标题模板

```
MMDD复盘：{反弹延续 | 继续修复 | 轮动修复 | 第一次回踩 | 缩量企稳}
```

变体（带情绪色彩）：`MMDD复盘：如期反弹`、`MMDD复盘：回踩守住`、`MMDD复盘：反弹的第一根阴线`

## 内容结构（1500-3000 字）

```
【今日操作】
1. {持仓股}：{具体动作，如"持仓不动"/"加仓XX元"}；
2. ...

【今日洞察】
1. 大盘
   1）走势：{点位变化、关键压力位、形态描述}
   2）量能：{放量/缩量、与前几日对比}
   3）赚钱效应：{涨跌家数、涨跌停比、热点板块宽度}
   {对反弹强度的判断 + 对回踩的预期}

2. 板块
   1）{反弹主线板块}：{强势表现 + 是 B 浪还是反转的判断}
   2）{其他活跃板块}：{状态 + 操作思路}
   ...

3. 个股
   1）{持仓 1}：{技术面 + 关键位 + 操作}
   2）{持仓 2}：...
   3）{持仓 3}：...

【写在最后】
{本文所提到的观点仅代表个人的意见，所涉及标的不作推荐，据此买卖，风险自负。
坚持分享不易...}
```

## Few-shot 示例 1：0804复盘：轮动修复

**标题**：0804复盘：轮动修复

**正文**：
```
【今日操作】
石头科技 & 国芳集团 & 沪电股份 & 大元泵业 & 科创50etf：持仓不动；

【今日洞察】
1.大盘
1）走势：高开后再次下探3800下方，但这次只是轻轻刺破，后面冲高回落，最后收在3822.28；
上证的企稳迹象进一步加强，如果没有大的外部事件，这里3741就是阶段底部了，后面几个月就是围绕这个底部做修复；
2）量能：2.21万亿，小幅放量；
3）赚钱效应：涨跌比3642:1747，涨跌停比140:1；
依然是跌停家数极少的一天；虽然放的量不大，但是个股普遍在修复；这里的思路主要是持仓不动等待轮动，修复完你的修复他的；科技股尤其是半导体是最后跌的，大家都跌了一遍后，高位方向就不多了，市场整体的风险得到了释放；不过目前主线依然不太清晰，板块的延续性一般；这是底部刚开始修复的特征之一，资金都在试，直到试出来一个市场合力的方向；

2. 板块
1）证券&金融科技：横盘震荡，整体量不大，从今天的结构来看，这里选择方向向上的可能性更大一些；
2）银行：连续惯性上攻后，今天还是收出中阴线，守住10日线有难度，本周先看下20日线的支撑；银行其实算是最近相对高位的方向；
3）PCB：完成筑底的可能性在加强，现在就是需要观察是否能至少连续3天站稳10日线，而且盘中回踩的时候是否缩量，如果满足这些条件的话，那么这里很可能就是一波反弹的起点；不过结束结构的反转还是需要时间来消化；
4）半导体：直接选择高开，没有再探底，以一根大阳线完成止跌，是偏强的信号，不过反转还早，还是太缺量；
5）机器人&汽车零部件：明确底部反转，还差一点点量把价格推到20日线上方；
6）电池：继续看反弹，还差一个放量阳线站回20日线的动作；
7）商业航天：超跌反弹，延续性不确定，但是混过本周应该没什么问题；不适合长期持有；

3. 个股
1）沪电股份：筑底过程中的第一次强烈多头信号，好的迹象；
技术面上，日线的重心明显抬升，而且反弹的量推升得很温和，抛压不大；这里反弹的压力位还是看123，需要量能的支持，才能消化上方的套牢盘；再次回到10日线上方后，需要连续至少连续三天能站稳10日线，才有可能真正修复技术结构；
2）三花智控：低开高走，反弹的趋势很健康，20日线只是一个比较小的压力位，真正的压力位还是看45；；
3）石头科技：横盘的第三天，小阴线伴随极致缩量，这个位置只有一些短线获利盘，抛压不会太大；主要还是看本周是否能依托20周均线继续修复结构，短线的支撑位在108和106；
4）国芳集团：缩量横盘，均线上移，暂时还没有否定7月29-31日三根放量K线的结构，暂时还是看多；
5）中际旭创：能站回10日线是非常强势的表现，唯一的遗憾是放的量不够，这里如果量比超过1.5，会是非常强烈的筑底信号；
```
