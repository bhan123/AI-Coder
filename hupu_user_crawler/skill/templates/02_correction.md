# 模板 02：下跌调整

适用场景：大盘/持仓大跌，市场恐慌，止损还是扛的决策时刻。关键词：恐慌、杀跌、破位、跳空、止损、清仓、跑路、扛、底部确认。

代表帖：
- 1215复盘：不用杀恐慌盘了，我自己会走 (2604 字)
- 1105复盘：极致恐慌后，大资金终于开始下单了 (2420 字)

---

## 风格规则

- **主旋律**：承认下跌的真实性，但区分"恐慌盘"和"基本面恶化"
- **核心叙事**：从恐慌 → 看到资金动作（"大资金开始下单"）→ 给应对方案（加仓/止损/扛）
- **板块视角**：恐慌时高估值/高位股先跌；防御板块（银行/红利）相对抗跌
- **个股视角**：看持仓股基本面有没有变化，技术位是否破位
- **关键术语**：恐慌盘、杀跌、底部确认、左侧交易、右侧止损、破位、护盘
- **情绪基调**：平静（不像普通散户那样宣泄愤怒），克制但有判断

## 标题模板

```
MMDD复盘：{暴跌 | 恐慌 | 破位 | 不用杀恐慌盘 | 大资金开始下单}
```

变体：`MMDD复盘：扛过来了`、`MMDD复盘：底来了吗`、`MMDD复盘：先不要恐慌`

## 内容结构（1500-3000 字）

```
【今日操作】
{重点说明今天对持仓的具体动作（加仓减仓的逻辑），强调"按计划"}

【今日洞察】
1. 大盘
   1）走势：{暴跌幅度、关键位是否破位}
   2）量能：{恐慌量还是缩量}
   3）情绪：{今天有多少恐慌盘、跌停家数}
   {判断是恐慌还是真要离场}

2. 板块
   1）{杀跌最猛的板块}：{是否需要止损}
   2）{逆势抗跌板块}：{是否能成为避险方向}
   ...

3. 个股
   {每只持仓股：今天表现 + 技术位 + 应对}

【写在最后】
{免责+鼓励}
```

**正文**：
```
【今日操作】
1. 沪电股份：止损卖出；
2. 国芳集团：止损卖出；
3. 石头科技：止损卖出；
4. 大元泵业：止损卖出；
5. 科创50ETF：止损卖出；
6. 惠科股份：今天建仓，买在地板上；

【今日洞察】
1.大盘
1）走势：低开低走，破位下行，今天最低跌到了 3850 附近，尾盘在 3870 附近；
2）量能：2.4 万亿，放量下跌；
3）赚钱效应：涨跌比 712:4472，涨跌停比 12:67；
盘面非常难看，跌停家数大幅增加；大部分是前期涨幅较大的科技股；今天市场情绪非常悲观，恐慌盘涌出；

2. 板块
1）半导体：大幅杀跌，前期龙头股跌停；这次和 4 月 7 日不同，不是受外部冲击，是基本面恶化；前期涨幅过大，估值过高，业绩跟不上；现在不是抄底的时候，等止跌再说；
2）PCB：跌停潮；技术形态完全破坏；这次跌下来，至少要盘整几个月；
3）光模块：暴跌；前期涨幅过大，这次跌下来基本上把今年的涨幅都跌没了；
4）机器人：跟跌，没有独立行情；
5）银行：相对抗跌，但也没怎么涨；
6）红利：今天小幅上涨，是避险方向；

3. 个股
1）沪电股份：今天跌停，破位下行；技术形态完全破坏；这次止损卖出是对的；
2）国芳集团：今天跌停，破位下行；止损卖出；
3）石头科技：今天跌停，破位下行；止损卖出；
4）大元泵业：今天跌停，破位下行；止损卖出；
5）科创50ETF：今天跌停，破位下行；止损卖出；
6）惠科股份：今天建仓；逻辑是公司基本面优秀，业绩持续增长，估值合理；这次大跌给了很好的买入机会；

【写在最后】
本文所提到的观点仅代表个人的意见，所涉及标的不作推荐，据此买卖，风险自负。坚持分享不易，如果我的文章帮助你赚到了钱，请不要吝惜充电、投币和打赏的手，这对我是很大的认可和鼓励，也请把我的文章分享给朋友们一起赚钱；如果暂时没赚到钱，也可以多多帮忙点赞收藏分享，希望我的文章未来可以帮你赚到钱。
```

**注意**：这是少见的全止损日。日常下跌中**应更克制**，不要每只都止损，而是强调"按计划"。

## 反模式

- ❌ 写成"今天亏了 X 万，心态崩了"
- ❌ 没有应对方案，只描述痛苦
- ❌ 把所有下跌都归因为"主力出货"
- ❌ 给"建议割肉"或"建议抄底"的二元结论
- ❌ 没有"大资金动向"或类似结构性观察
