# 虎扑股票复盘写作 Skill

基于用户 `19134213076193`（虎扑名"巴萨主教练弗里克"）的 **446 条历史主贴**（2025-01-02 ~ 2026-08-06，共 72 万字）训练的写作风格库。

---

## 怎么用

### 1. 选模板

看 `selector.md`。根据今日市场和时点选模板：

| 模板 | 适用 | 字数 |
|------|------|------|
| `templates/01_bounce_recovery.md` | 反弹/修复/企稳日 | 1500-3000 |
| `templates/02_correction.md` | 大跌/恐慌/破位日 | 1500-3000 |
| `templates/03_sideways_rotation.md` | 震荡/缩量/轮动日 | 1200-2000 |
| `templates/04_operation_hold.md` | 重大调仓日 | 1500-3500 |
| `templates/05_intraday.md` | 盘中/午盘快评 | 200-500 |
| `templates/06_premarket.md` | 盘前预判 | 300-800 |

### 2. 打开模板文件

每个模板里有：
- **风格规则**（主旋律、核心叙事、关键术语）
- **标题模板**
- **内容结构**（段落纲要）
- **Few-shot 示例**（1-2 条真实历史帖）
- **调用 prompt**（直接复制粘贴用）
- **反模式**（避免这些写法）

### 3. 复制「调用 prompt」段

把模板里的 `## 调用 prompt` 整段复制到 Claude 对话框，把 `{今日数据}` 占位符替换成今天的真实数据。

### 4. 调整输出

让 Claude 输出后，检查：
- 标题是否符合 `MMDD复盘/盘中/盘前：xxx` 格式
- 6 段结构是否完整（或盘中帖省略「写在最后」）
- 关键术语是否到位（反弹/修复/回踩/高低切/抱团/轮动/破位/恐慌）
- 字数是否符合预期

## 实战示例

### 场景：今天是 2026-08-07，收盘后发现：
- 上证 +0.8%，成交量 2.5 万亿（放量）
- 半导体、PCB 领涨，跌停仅 5 家
- 持仓股普遍上涨

**步骤**：
1. 打开 `selector.md` → 选 `templates/01_bounce_recovery.md`
2. 复制该模板的 `## 调用 prompt` 段
3. 替换占位符：
   ```
   ## 今日数据
   2026-08-07 收盘：
   - 上证 +0.8% → 3890 点
   - 深成 +1.2% → 12500 点
   - 成交量 2.5 万亿（较 5 日均 +20%）
   - 涨跌停比 78:5
   - 半导体 +3.2%（领涨）、PCB +2.8%
   - 持仓：沪电股份 +4.5%、石头科技 +1.2%、国芳集团 +0.8%
   ```
4. 贴到 Claude API / claude.ai 对话框
5. Claude 输出符合风格的复盘

### 场景：今天是 2026-08-07 上午 11 点
- 大盘低开 1%，半导体急跌 3%

**步骤**：
1. 打开 `templates/05_intraday.md`
2. 复制调用 prompt，填入盘中数据
3. Claude 输出 200-500 字的盘中快评
