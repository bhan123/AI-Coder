# 虎扑股票复盘写作 Skill

按虎扑用户 "巴萨主教练弗里克" 的写作风格，生成每日股票复盘。

## 何时使用

- 用户说"写一篇今日复盘"、"模仿这个虎扑用户写一篇"、"按 skill 库生成..."
- 用户提供今日市场数据（指数/板块/持仓），要生成虎扑格式的复盘
- 用户说"hupu-stock-recap"、"巴萨主教练弗里克风格"

## 工作流程

### Step 1: 读 selector.md 决定用哪个模板

询问用户（或自己判断）以下信息：

1. **时点**：盘前 / 盘中 / 收盘后？
2. **市场状态**：涨 / 跌 / 震荡？
3. **是否有大动作**：加仓 / 减仓 / 清仓？

根据 selector.md 的决策树选模板。

### Step 2: 读对应模板文件

每个模板里有：
- 风格规则
- 标题模板
- 内容结构
- Few-shot 示例
- 调用 prompt（最重要的，直接复制用）
- 反模式

### Step 3: 让用户提供今日数据

最少需要：
- 大盘涨跌幅 + 成交量 + 关键点位
- 涨跌停家数（反映赚钱效应）
- 2-4 个领涨/领跌板块
- 持仓股表现（如有）

### Step 4: 复制模板的「调用 prompt」段，替换占位符

```markdown
你是虎扑用户「巴萨主教练弗里克」的写作风格模仿助手。
请基于以下今日市场数据，按「{模板名}」模板写一篇 MMDD 复盘帖：

## 今日数据
{用户提供的今日行情}

## 写作要求
{模板里的具体要求}

## 参考样例
{模板里的 few-shot 示例}

## 输出格式
完整虎扑帖子格式输出。
```

### Step 5: 输出检查清单

- 标题格式：`MMDD复盘/盘中/盘前：xxx`
- 6 段结构（或盘中帖省略「写在最后」）
- 关键术语到位
- 字数符合模板预期

## 输出格式

直接输出虎扑格式的帖子文本（含标题和正文），不需要 markdown 包装。

用户得到输出后，可以直接复制到虎扑发帖。
