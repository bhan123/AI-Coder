# 爱意存折（爱折）· 微信小程序版

爱意存折（简称“爱折”）是一款供两位明确同意的伴侣共同使用的微信小程序。它把行动、感受、回应和约定留在一个仅双方使用的共同空间里，并提供一套可追溯的“爱意分数”机制。

本目录是独立的 Taro + React + CloudBase 项目。它不会读取、修改或连接现有 H5 项目的 SQLite 数据库、服务或部署。

## 产品规则

### 1. 双人配对与初始分数

1. 创建者填写称呼并设定一个 `0–100` 的建议初始分数，生成一次性邀请码。
2. 受邀者输入邀请码后可读取这个建议值，也可以修改。
3. 受邀者点击确认时填写的分数，才会成为两人的最终共同初始分数。
4. 邀请码仅能使用一次，24 小时后失效；任何账号同一时间只能处于一个共同空间。

### 2. 行动：对方审批后加分

- 任一方可提交一条行动，并建议 `+1 / +3 / +5` 分。
- 提交本身不会立即加分。
- 另一方可以通过并决定实际加 `+1 / +3 / +5` 分，或直接驳回。
- 审批结果、实际分数和当前总分在同一个云端事务内保存，不能重复审批或覆盖。

### 3. 感受：即时扣分，仍需回应

- 任一方可记录一条感受，并选择 `-1 / -3 / -5` 分。
- 提交后分数立即扣减，且会保留“等待认真回应”的入口。
- 回应只允许写入一次；回应不自动撤销扣分。

### 4. 手动调分：必须双方确认

- 除行动审批与感受直接扣分外，任何手动修改当前分数都必须先提交申请，写明原因和目标分数。
- 另一位伴侣确认后才会生效；驳回则不改变分数。
- 这类申请也会保留在共同历史中。

### 5. 默认分段文案

| 分数 | 状态 |
| --- | --- |
| 90–100 | 爱意炽烈 |
| 75–89 | 甜蜜在线 |
| 60–74 | 温柔待机 |
| 40–59 | 需要充电 |
| 20–39 | 修复时刻 |
| 0–19 | 暂停计分 |

低于 20 分时，首页会显示关怀提醒：暂停争论加减分，优先回到安全、倾听和具体沟通。分数用于提示和回顾，不应作为审判、排行、控制或“兑换原谅”的工具。

## 已实现功能

- 微信 OpenID 身份映射与一次性双人邀请；
- CloudBase 云函数授权，前端不直接读写业务集合；
- 行动、感受、回应、共同约定、调分申请与审批历史；
- 近 1 月、近 3 月、全部历史筛选，以及云端游标分页加载；
- 幂等操作凭证、服务端频控、事务审计与并发配对保护；
- 微信内容安全检查：仅在身份、共同空间权限和当前隐私同意都通过后发送文本检查；
- 免费导出本人原始数据；导出不包含伴侣正文或伴侣回应；
- 超出一次复制上限时可按稳定快照分段导出本人记录和本人贡献，避免大数据量静默截断；
- 撤回邀请、退出共同空间、本人删除、双方确认共同删除；
- 业务库 7 天内删除、应用自建备份最迟 30 天清理，以及清理积压告警字段；
- 返回小程序自动刷新和下拉刷新，降低两台手机之间的状态滞后；
- 原生分享邀请与可扫码的小程序码（需在已关联 AppID 的 CloudBase 环境中启用）；
- 可选的照片附件上传：默认关闭，只有完成云存储私有权限、隐私指引与真机验收后才可开启；
- 订阅消息出站队列：提醒文案不包含伴侣正文，授权一次仅消耗一条消息配额；
- 仅白名单 OpenID 可访问、且不展示用户正文的最小化运营指标页；
- 未配置 CloudBase 时的本地体验模式，可切换双方视角验证交互。

## 安全与边界

- 这是关系记录和沟通辅助工具，不是婚姻治疗、紧急干预或安全求助服务。
- 严重控制、威胁、暴力或任何一方感到不安全的关系，不应依赖本工具调解；应优先寻求可信的人、专业机构或紧急帮助。
- 小程序界面仅向共同空间的两位伴侣展示内容；CloudBase 管理员及经授权的运维/安全人员在排障、安全事件或法律义务所必需时，理论上可能访问原始数据。不得宣传为“任何第三方绝对无法读取”。
- 请不要填写身份证号、银行卡、精确住址、医疗诊断、未成年人信息或无权提供的第三方秘密。

完整的数据处理、导出、删除和上线前置条件见：[CloudBase 上线清单](./docs/cloudbase-setup.md) 与 [隐私说明草案](./docs/privacy-notice-draft.md)。

## 本地开发

安装依赖：

```powershell
npm install
```

运行测试：

```powershell
npm test
```

构建微信小程序：

```powershell
npm run build:weapp
```

持续构建：

```powershell
npm run dev:weapp
```

构建产物输出到 `dist/`。用微信开发者工具导入本目录；首次可保留 `project.config.json` 中的测试 AppID，创建自己的小程序后替换为自己的 AppID。绝不把 AppSecret 写入仓库。

同一项目提供 H5 视觉预览，仅用于本地界面检查：

```powershell
npm run dev:h5
```

它不等同于原有 H5 项目，也不能替代微信真机验证。

## 接入 CloudBase

默认 [`src/config/cloudbase.ts`](./src/config/cloudbase.ts) 中的环境 ID 为空，因此只会启用本地体验模式，不会上传记录。

要启用两部手机上的真实配对与云端同步：

1. 开通微信云开发并创建 `test` 环境；
2. 填写 AppID 与 CloudBase 环境 ID；
3. 上传并部署 `relationship-api`、`privacy-cleanup`、`notification-dispatch` 与 `operations-api` 四个云函数，并保留各自的 `package-lock.json`；
4. 将业务集合设置为仅云函数读写，建立文档要求的索引；
5. 为 `privacy-cleanup` 配置每小时触发器；为 `notification-dispatch` 配置每 5 分钟触发器，并对失败、积压及 `requiresAttention` 配置告警；
6. 配置微信《小程序用户隐私保护指引》，再用两个真实微信号完成配对、审批、扣分、导出和删除验收。

详细控制台操作和上线阻断项见 [CloudBase 上线清单](./docs/cloudbase-setup.md)。在清理任务、数据权限、隐私指引和访问审计没有全部完成前，只能使用虚构测试数据。
